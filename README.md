# Ecovacs Legacy (XMPP) para Home Assistant

Integración personalizada para aspiradores Deebot **OZMO 930** (y otros modelos XMPP/XML) que la
integración oficial no soporta bien. Cliente XMPP propio con asyncio; `deebot-client` solo para login.

- Instalación: [INSTALL.md](INSTALL.md)
- Comandos y protocolo: [docs/OZMO930_COMMANDS.md](docs/OZMO930_COMMANDS.md)
- Pruebas: `python -m pytest -q`
